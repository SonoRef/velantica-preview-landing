# velantica-preview-landing

Static teaser page for velantica.com: black background, emerald/teal light, wordmark, "Something is coming."

No build step, no dependencies, no external requests. Open `index.html` directly or serve the folder:

    python3 -m http.server 8080

Hosting and DNS for velantica.com are not set up yet; this repo only holds the page.
